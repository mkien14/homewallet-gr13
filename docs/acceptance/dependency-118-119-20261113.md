## Thay đổi

- React và React DOM cùng `19.3.1` trong lock và cùng range `^19.3.1` trong
  package.json. Thêm test đọc manifest/lock, kiểm tra phiên bản đang cài và render
  component dùng hook. Dependabot nhóm hai package để tránh nâng riêng renderer.
- Redis Python client lên `8.1.0`, requirements `>=8.1.0,<9`, lock và SHA256
  wheel/sdist từ PyPI đồng bộ. Chỉ Redis đổi phiên bản trong 56 package runtime;
  build kiểm tra hash và pip check. Không nâng Redis server/ElastiCache.
- Giữ RESP2 rõ ràng để tránh đổi wire protocol theo mặc định thư viện mới.
  Tắt tự chạy lại command sau mất kết nối nhằm tránh đếm lặp INCR/EVAL khi reply
  bị mất. Giữ TLS bắt buộc, xác minh CA/hostname, AUTH và socket timeout.
- Thay SETEX deprecated bằng SET với EX; TTL cache vẫn giữ nguyên.
- Thêm kiểm tra requirements/lock, test Redis thực qua TLS có mật khẩu và CI
  chạy helper tạo Redis cục bộ dùng container digest cố định. Helper chỉ xóa
  container có tên riêng do chính lần chạy tạo; không thao tác Redis AWS.
